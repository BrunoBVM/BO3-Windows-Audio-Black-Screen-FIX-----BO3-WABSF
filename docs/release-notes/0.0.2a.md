## v0.0.2a (alpha)

Second test build of the proxy. Adds the `winmm` device-count clamp, which is what fixed the Black Ops III black screen / freeze on the author's machine.

**Install:** copy `dsound.dll` next to `BlackOps3.exe`. Optional `dsound_proxy.cfg` with one number sets the cap (default 16). Check `dsound_proxy.log` for `clamp cap=16; import slots patched: ...`. Delete the DLL to remove it.

**Tested:** one machine, Windows build 26100. `mixerGetNumDevs real=28 -> returned 16`; the game reached the menu.

**SHA-256:** `971001F82716D9739C58EE3FE451CAB3E3565AA04492E6553FDA5871033FAC88`

**Built with:** MinGW-w64, `g++ -shared -O2 -static -o dsound.dll src/dsound.cpp src/dsound.def`

**Caveats**
- Alpha, unsigned, tested on one setup only. Some antivirus programs may flag proxy DLLs.
- Intended for offline, solo and LAN play. Read the anti-cheat section of the README before using it.
- If the log shows every patched import count as 0, this build does not help on your setup.
