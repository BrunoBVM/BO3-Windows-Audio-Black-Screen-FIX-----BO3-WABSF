## v0.0.2a (alfa)

Segunda versão de teste do proxy. Adiciona o clamp de contagem de dispositivos do `winmm`, que resolveu a tela preta / travamento do Black Ops III na máquina do autor.

**Instalação:** copie a `dsound.dll` para ao lado do `BlackOps3.exe`. Um `dsound_proxy.cfg` opcional com um número define o limite (padrão 16). Procure em `dsound_proxy.log` por `clamp cap=16; import slots patched: ...`. Apague a DLL para remover.

**Testado:** uma máquina, build do Windows 26100. `mixerGetNumDevs real=28 -> returned 16`; o jogo chegou ao menu.

**SHA-256:** `971001F82716D9739C58EE3FE451CAB3E3565AA04492E6553FDA5871033FAC88`

**Compilado com:** MinGW-w64, `g++ -shared -O2 -static -o dsound.dll src/dsound.cpp src/dsound.def`

**Ressalvas**
- Alfa, sem assinatura, testado em uma única configuração. Alguns antivírus podem sinalizar DLLs proxy.
- Pensado para jogo offline, solo e em LAN. Leia a seção de anti-cheat do README antes de usar.
- Se o log mostrar todas as contagens de importação alteradas como 0, esta versão não ajuda na sua configuração.
